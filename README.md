# Bugged

A draft YSWS where you pretty much make anything with bugs, granted that the bugs be intentional.

### What does "intentional bugs" mean?

A. Imagine you have a game. An "intentional bug" could be a bug that helps the player progress forward in the game.

- A pause glitch where if you pause, your enemies would be frozen in time, but you could still move forward.
- A block on which you could both bounce & grab, grabbing the block and bouncing off of it mid-air, gaining an advantage

In hardware

- An mp3 player which is bugged to play white noise/rain sound whenever it isn't playing music, which seems soothing
- A desk lamp that when turned off displays a logo or something instead of fully turned off, forced advertisement :)

Be creative, go crazy!

### What do We Ship?

A. Debugging, Security and Puzzle related goodies!
Debugging - A Rubber Duck, A USB Drive, AI Credits etc.
Security - Flipper Zero, Yubikey, Raspberry Pi etc.
Puzzle - Rubik's Cube and stuff
